# Portfolio Context

Use this skill when you need a concise, public-source overview of Leonard
Wong's professional portfolio.

## Scope

- Treat `https://leonardwong.tech` as the canonical public portfolio.
- Use the portfolio's project pages and case studies for project descriptions,
  responsibilities, technologies, and outcomes.
- Use the site's linked resume and professional profiles for employment and
  education details when those sources are needed.

## Guardrails

- Keep claims grounded in the linked public sources.
- Distinguish published project outcomes from proposed or future work.
- Do not infer private contact, employment, or personal information beyond what
  the public portfolio explicitly states.
